# Languages (French, English)

French is the source language. The app speaks French or English, the server writes push, inbox, e-mails and share cards in each person's language, and each room picks the language of its questions.

## App strings

- Every user-facing string lives in `app/src/locales/fr/<namespace>.ts` with the same key in `app/src/locales/en/<namespace>.ts`. `fr.ts` / `en.ts` gather the namespaces; tsc fails if a key is missing in English.
- In a component: `const t = useT();` then `t('vote.title')`. `useT()` re-renders the component when the language changes. Outside components (helpers, module code): `import { t } from '@/lib/i18n'`, called at render or event time, never at module load (a constant computed at import stays in the first language).
- Placeholders: `'{name} a voté'` → `t('vote.voted', { name })`.
- Plurals: `{ one: '{count} vote', other: '{count} votes' }` (optional `zero`) → `t('vote.count', { count: n })`. French counts 0 and 1 as singular, English only 1.
- Dates and numbers: `dateFormat({ day: 'numeric', month: 'short' }).format(d)` and `formatNumber(n)` from `@/lib/i18n` (cached per language). Never hardcode `'fr-FR'`.
- Server error codes (`{"error": "bad_code"}`) are translated by the app (`errors` namespace, `authError()` in `lib/auth.ts`).
- English is natural English, not a word-for-word translation; keep it as short as the French.

To add a string: add the key to the French namespace file, the same key to the English one, use `t('ns.key')`. A new namespace: create both files and add them to `fr.ts` and `en.ts`.

## Language setting

Profile → Langue: Automatique (phone language: French stays French, anything else is English) / Français / English. Stored on the device (`qdn.lang`) and on the account (`PUT /api/me/locale`), so a new device adopts it at sign-in. An install that was signed in before this setting existed stays in French.

## Server API

- `GET /api/me/locale` → `{ locale: 'fr' | 'en' | null, pref: 'auto' | 'fr' | 'en' | null }` (null = never set, treated as French).
- `PUT /api/me/locale { locale: 'fr' | 'en', pref: 'auto' | 'fr' | 'en' }` → same shape; `400 bad_locale`. `locale` is the language the app shows (resolved from `auto`), the one the server uses for that person.
- `POST /api/auth/signup { …, locale? }`: optional `'fr' | 'en'` (anything else ignored), stored as `users.locale` so the verification e-mail sent right away is already in the app's language.
- `users.locale` drives push notifications (per device, by its account), inbox texts (stored in the recipient's language when written), account e-mails (verification codes, password reset, account deletion; by e-mail address: the account's language, else French), stats stories (`GET /api/stats`, the reader's language), the history CSV export, and share cards/pages (the sharer's language at share time, `shares.lang` / `stat_shares.lang`; sharing again after switching language makes a new link, old links keep theirs). Report e-mails to the team stay French.
- Rooms: `groups.language` (`'fr'` default). `POST /api/rooms { name, vibe?, language? }`, owner `PATCH /api/rooms/{id} { language }` (`400 bad_language`, only future questions change), `GET /api/group` (top level and in `settings`) and `GET /api/rooms` carry `language`; `POST /api/rooms` answers it too. `/start` and `/join` rooms are French. The built-in deck questions a room draws are those of its language (`server/deck/fr.txt`, `server/deck/en.txt`, same vibe tags); the room's own questions and packs are drawn whatever their language.
- Packs: `packs.language` (`'fr'` default), `POST /api/packs { …, language? }` (`400 bad_language`), returned in lists and details. Not filtered yet.
- Deleted accounts: the database keeps the placeholder name "Compte supprimé"; texts written for a reader (CSV, share cards/pages, stats stories) say "Deleted account" in English, and member JSON carries `deleted: true` so the app shows its own label.
- `GET /api/features` lists `languages` when the server has all this.
- Legal pages: `/privacy`, `/terms`, `/delete-account` (French), `/en/privacy`, `/en/terms`, `/en/delete-account` (English), each linking to the other language.

Old apps never send a language: their accounts and rooms stay French.
